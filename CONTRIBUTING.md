To the contributor,
First Off, Thank you for taking time to contribute !

## Security First : Keep credentials safe

**Never commit your credentials, keys, personal server api**
1. Project uses `.env` for variables
2. Actual `.env` is not tracked : Confidential Information

## Geting Started

1. Find a issue
2. Clone the repo
3. Setup your dev environment
4. keep your commits clean and discriptive for review
5. Raise PR
6. Get review -> Merge/changes -> Featured contributor listing
