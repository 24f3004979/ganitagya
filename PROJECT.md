# Project : Ganitagya

Detailed project discription and feature discription, with locked scope and build targets.Dedicated core components to build into this 3 week sprint.

1. Siddhi

    Adaptive Diagnostic quiz generator, with embeded error tracing,
    wrong options are maped to topics and difficulty adjustment with mistakes or correct answers.

    + Conceptual topics need subjective explicit maping with required article read and topics maping
    + Numerical Topics answer based documentation would be loaded with error embeded options for trace extraction.
    
2. Chintan

    Learning module with dedicated tools for exploration, explanation walkthrough. Numerical analysis tool with graphical and visual exploration tool dedicated for learning.

    1. Numerical Unit
        
        - Solving equations, Expression with algebraic simplication approach with steps break down 
    
    2. Geometrical Unit
        
        - Graphing equations and expressions
        - Geometric View for the algebraic expressions

3. Ankur

    Learning Material for topics with first version it would be just markdown rendered article for topic

    Topic Dedicated interactive elements loaded from chintan geometrical plugin for spark based article flow

    which instructs user to make the situation with the given elements, or come up with the equation with chintan tools

4. Mitra

    A LLM based orchistration layer which would serve as tutor who walk through the article with being grounded with article, navigating with asking nudge questions and helping to get directions in ankur article chintan phase, 

    Provide hints or nudges into siddhi module if require
