# Chintan Engine plan

Goal : Make mathematics explorative and adventurous with simulation, disection and interaction

## Engine Components
1. Numerical

Making numerical disection for given expression/Function/Equation
disecting its components into simpler form for easy understanding and grasp

### Approach

`tokenization -> parse -> dependency tree build -> evaluate`
Target tokenization for simplification into AST with operations being node and elements being leaf, recursively back substituting for evaluation of the expression into steps

Which would be  presented through the presentation layer as this part starts working :)

2. Graphical

Visualization from graphical and geometrical means for mathematical concepts using existing graphing library with sync with nuemerical module about expression.
