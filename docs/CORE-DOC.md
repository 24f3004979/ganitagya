# Project : Ganitagya Documentation v0.1

> Last Update : 2026-09-25

## About Project

An adaptive Learning application, with end goal of being a part of learning way for student, let them think and explore mathematics.

## Current User flow

Student can login, use chintan to explore numerical expression simplification, use siddhi for there testing and get report about which topic to focus on.

## Core Components | Aimed for First Launch

1. **Mool** : Core information graph

Vision : An knowledge root origin for application with retrival mechanism and root topics traversal bank, knowledge manager for application

Current Status : Contains root concepts graph, iteration end point for other units reference about topics to target.

2. **Siddhi**

Vision : Adaptive testing suit for student, which adjusts its questions based on student current knowledge, connected to Mool for information flow and updates student concept graph references.

Current Status : Simple questions generation sequence works with adjusting question difficulty with topic switch connection with mool graph/student references.

3. **Chintan**

Vision : An Exploration tool for student to experiment and play with numbers on own, his discovery is detected to celibrate when student accidently arrives at any new thing, helps student understand mathematical expressions with numerical and visual lens.

Current Status : Working Numerical parser with simple block animation to visualize the execution of arithmatic expression simplification.
